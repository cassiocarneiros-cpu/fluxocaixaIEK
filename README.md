NO CELULAR:
- TOQUE EM "TIRAR OU ESCOLHER FOTO".
- O NAVEGADOR PODERÁ ABRIR A CÂMERA TRASEIRA.
- TAMBÉM É POSSÍVEL ESCOLHER UMA IMAGEM DA GALERIA.
